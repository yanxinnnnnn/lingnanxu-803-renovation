## 概念阶段可做什么 / 必须等待 B1 什么

可以用五个高置信语义面积作为可撤销的概念预算，比较公共区功能关系、南次卧与 flex 的
用途取舍，以及 A/B/C 中家具类型和空间优先级。中置信候选用于列出假设和待确认问题，
未决区不提供任何房间预算。当前产物是 layout **input**，没有生成或冻结 A/B/C 家具布局。

B1 前不确认精确家具尺寸/数量/摆放适配、通道净宽、开门碰撞、柜体尺寸、曲面玻璃范围，
不进行施工放线、拆改或水电定位。净跨、墙厚、门窗开口、套房边界、承重/结构信息、
可见设备点位和实际可用区域均需 803 现场或适用官方证据。面积不能导出宽/深或矩形边长。

使用 [803 现场工作表](../measurements/onsite-survey-803.md) 收集独立 evidence，
新增 `onsite_measured` 或 `official` 记录；只有这两类来源可驱动 B1。
经复核与 Product Owner 验收后，B1 替代 provisional 输入；保留 B0.1/B0.2/B0.3 历史。

## 生成与校验

```bash
uv sync
uv run python scripts/validate_layout_input.py
uv run python scripts/generate_layout_input.py
uv run python scripts/validate_layout_input.py --dxf cad/LN803_LAYOUT_INPUT_B0.3_provisional_20261004.dxf
uv run pytest
git status --short
```

生成独立的 `cad/LN803_LAYOUT_INPUT_B0.3_provisional_20261004.dxf` 与
`artifacts/LN803_LAYOUT_INPUT_B0.3_provisional_20261004_preview.png`。
`A-LAYOUT-INPUT` 仅加入 TEXT 与独立 provenance XDATA；原 B0.1 实体逐一保持不变，
不产生 DIMENSION 或新 geometry。high/medium/unresolved 分别用绿/橙/紫色，
suite 候选标在三空间上方，精确包络仍未决。警告与原 B0 禁止施工注记同时可见。

`--data`、`--output`、`--preview` 可指定 review 路径；不能将旧 B0.1/B0.2 artifacts 或
输入文件作为输出。验证失败返回非零状态；生成固定 DXF metadata/LF 和 PNG metadata。
原有 B0.1/B0.2 命令继续有效，在已提交的干净 checkout 上完整 cycle 不改变 artifacts。
