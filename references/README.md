# References

这里保存**资料索引和说明**。大体积原文件优先放外部持久存储，Git 仓库保存可追踪的 manifest 和校验值。

当前原始资料包括：
- 纸质营销户型图手机照片
- 118㎡交付样板间视频

## Canonical source tracking

关键原始资料登记在：

`references/source-manifest.yaml`

其中记录：
- 原始文件名
- 存储位置
- baseline
- 用途
- SHA-256 校验值

当前交付样板间视频已经登记为 `showroom-001`，作为 B0 阶段的空间与交付状态参考。

原则：
1. 原始资料只追加、不覆盖。
2. 设计过程中产生的裁剪图、转码文件不得替代原始文件。
3. 外部二进制资料必须通过 manifest 保留可追踪信息。
4. 视频只能用于空间、材质、门窗等视觉判断，不能替代实测尺寸。
